## Description du projet

AfriConnect Summit 2026 est un projet de création d'un site vitrine moderne pour une conférence tech panafricaine fictive réunissant développeurs, entrepreneurs et investisseurs.

Le site sera développé avec HTML5, CSS3, JavaScript Vanilla, Git et GitHub.
