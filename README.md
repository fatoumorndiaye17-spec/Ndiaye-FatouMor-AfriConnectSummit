Description du projet
AfriConnect Summit 2026 est un site web vitrine réalisé dans le cadre de l’examen de développement web L1.
Le projet présente une conférence tech panafricaine fictive qui réunit développeurs, entrepreneurs et investisseurs autour de plusieurs thématiques liées à l’innovation numérique en Afrique.
L’objectif est de concevoir un site moderne, fluide, responsive et interactif en utilisant uniquement HTML5, CSS3 et JavaScript Vanilla.
Technologies utilisées
HTML5
* Structure sémantique :
    * header
    * nav
    * main
    * section
    * article
    * footer
* Création des 4 pages principales :
    * Accueil
    * Programme
    * Intervenants
    * Contact
* Formulaire d’inscription complet
* Gestion de l’accessibilité avec les attributs alt et aria-label
CSS3
* Variables CSS personnalisées
* Flexbox
* CSS Grid
* Responsive Design avec media queries
* Animations et transitions
* Mode sombre avec variables CSS
* Google Fonts
* Design moderne adapté aux événements technologiques
JavaScript Vanilla
Les fonctionnalités JavaScript développées sont :
* Dark Mode / Light Mode avec localStorage
* Menu hamburger responsive
* Navbar dynamique au scroll
* Bouton retour en haut
* Année dynamique dans le footer
* Compte à rebours de l’événement
* Onglets du programme Jour 1, Jour 2 et Jour 3
* Filtrage dynamique des intervenants
* Compteurs animés avec IntersectionObserver
* Animations au scroll
* Validation complète du formulaire :
    * champs obligatoires
    * vérification email
    * vérification téléphone
    * contrôle du message
    * messages d’erreur
    * message de succès

Conclusion

AfriConnect Summit 2026 représente une expérience web moderne pour présenter un événement technologique panafricain avec une interface fluide, accessible et responsive.
